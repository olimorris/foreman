# 8. The user's rules for what Foreman must never do live in the never list in .foreman/config.json and reach the orchestrator, every brief and the reviewer

A rule written once applies to every session in the run, including after a restart. Rejected: notes (`foreman note`), which record facts about the setup rather than rules, and a hook that blocks commands, which can't check plain-English rules. A hook for the rules it can check is follow-up work.
